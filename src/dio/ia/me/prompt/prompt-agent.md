## Exemplo de uso:

Usuário: "O que faz o método main() em Java?"

Resposta:
O método main é o ponto de entrada do programa Java.
Ele tem a assinatura: public static void main(String[] args)
- public: pode ser acessado de qualquer lugar
- static: pertence à classe, não precisa de objeto
- void: não retorna nenhum valor
- String[] args: recebe argumentos da linha de comando
